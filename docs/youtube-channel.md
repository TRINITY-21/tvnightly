## Suggested video pillars (content → site funnel)

| Format | Hook | Lands on |
| --- | --- | --- |
| "Every episode of X, ranked" | viral ranking | `/guide/<show>` or `/show/<show>/best-episodes` |
| "Where to watch X in 2026" | high-intent search | `/show/<show>/where-to-watch` |
| "How to watch the X universe in order" | franchise explainer | `/tv-watch-order/<universe>` |
| "X vs Y — which is better?" | debate bait | `/compare/<a>-vs-<b>` |
| "What's on tonight" / "What just got renewed" | recurring, live data | `/tonight`, `/renewals` |

All of these already exist as shareable pages on the site (with OG cards) — link them in the
description and pinned comment to drive traffic back to tvnightly.com.
